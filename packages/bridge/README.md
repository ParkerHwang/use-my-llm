# @use-my-llm/bridge

A loopback-only bridge for use-my-llm. It accepts website requests only after local approval of an exact origin, and uses the locally configured provider mode to generate text.

After installation, run `use-my-llm`. `localhost-agent` starts the same bridge. The default port is `127.0.0.1:43189`; `--port` and repeatable `--allow-origin` are local configuration options. The user must separately install and sign into the official Codex CLI. Claude has two explicit local modes. Run `use-my-llm claude-auth connect` for the official Claude Code CLI’s subscription sign-in; it uses a bridge-owned config directory and counts against your Claude plan limits. `claude-auth status` reports coarse connection state, `claude-auth mode api-key` selects API-key mode, and `claude-auth disconnect` logs out the bridge subscription and disables Claude. These are local commands, never HTTP endpoints. The compatible `--enable-claude-api` flag requires `ANTHROPIC_API_KEY` and may incur API charges. Its continuation path uses `--bare` and cannot fall back to a subscription. `--enable-antigravity-api` requires separate Gemini API credentials and does not reuse consumer desktop subscriptions. Run `use-my-llm --help` for options.

See the repository's [README](../../README.md), [security guidance](../../SECURITY.md), and [protocol](../../docs/PROTOCOL.md). This is a developer preview, not a general-purpose sandbox. MIT licensed; provider software and services have separate terms.
